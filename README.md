## 📊 Dashboard no Power BI

O projeto Customer Analytics foi desenvolvido no Power BI para analisar o desempenho comercial de uma empresa fictícia de varejo.

O dashboard contém cinco páginas:

- Visão Geral
- Análise de Produtos
- Análise de Clientes
- Performance
- Insights de Negócio
